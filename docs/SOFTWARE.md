# Software

Install the packages needed for the modules you intend to run:

```r
# Specificity tables and MDTPS Excel input/output
install.packages(c("readxl", "dplyr", "tidyr", "openxlsx"))

# Single-cell analysis (Seurat v5) and virtual knockout
install.packages(c("Seurat", "harmony", "data.table", "Matrix"))
install.packages("remotes")
remotes::install_github("cailab-tamu/scTenifoldKnk")
```

The MDTPS function and synthetic example use base R only. No analysis script installs packages automatically.

The observed local environment included R 4.5.2, Seurat 5.1.0, SeuratObject 5.0.2, Harmony 1.2.0, Matrix 1.7-4 and data.table 1.15.4. `dependency_versions.csv` records the observed downstream-module package versions. These records are not a complete environment lockfile. The original scTenifoldKnk version/commit was not recorded; its installation source above comes from the supplied scripts. Keep the `sessionInfo.txt` generated by each run.
